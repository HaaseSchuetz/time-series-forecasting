# Minimal Forecasting Pipeline

A lightweight ARIMA-based time series forecasting pipeline using the classic AirPassengers dataset.

## Quick Start

1. **Clone and setup:**
   ```bash
   git clone <your-repo-url>
   cd forecasting-pipeline
   pip install -r requirements.txt
   ```
2. **Run the notebook:**
```bash
jupyter notebook forecasting_pipeline.ipynb
```



**Requirements**

* Python 3.8+
* Packages listed in requirements.txt

**Contents**

* forecasting_pipeline.ipynb: End-to-end pipeline with EDA, modeling, forecasting, and evaluation
* ARIMA with seasonal component
* MAE, RMSE, MAPE metrics
* Visualizations for time series, forecasts, and residuals
